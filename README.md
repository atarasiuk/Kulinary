# Kulinary

Домашняя кулинарная книга: проверенные рецепты, меню на неделю и лайфхаки.
Рецепты пишутся для новичка: точные граммы, время и температура, без «на глаз», с заменами и частыми ошибками.

## Как добавить рецепт

1. Откройте [`templates/recipe.md`](templates/recipe.md) и скопируйте содержимое.
2. В нужной папке `recipes/...` нажмите **Add file → Create new file**.
3. Имя файла — транслит через дефис: `indeyka-v-aerogrile.md`.
4. Заполните метаданные между линиями `---` и разделы рецепта.
5. Добавьте строку в таблицу «Рецепты» на этой странице.
6. После готовки: дата в `cooked`, статус, оценка `rating`, фото в `images/`.

## Формат рецепта

Каждый рецепт начинается с блока метаданных YAML — GitHub показывает его таблицей над текстом:

```yaml
---
title: Дорада целиком в духовке
category: dinners
subcategory: fish
status: не готовил
servings: 2
prep_time: PT25M      # ISO 8601: 25 минут
cook_time: PT25M
total_time: PT55M
difficulty: 2         # 1–5
kcal_per_serving: 350
lactose: нет
days: [воскресенье]
tags: [духовка]
---
```

Дальше всегда одни и те же разделы: Кратко → Ингредиенты → Инвентарь → Пошагово → Безопасность → Замены → Частые ошибки → Источник и адаптация → Мои результаты.

## Правила именования

- Файлы и папки — латиница, строчные буквы, дефис: `kartofel-po-derevenski.md`.
- Одно блюдо — в одной папке; дополнительные признаки — в `tags`.
- Фото: `images/<папка рецепта>/<имя рецепта>-ГГГГ-ММ-ДД.jpg`.
- Меню: `meal-plans/ГГГГ/ГГГГ-Wнн.md`.
