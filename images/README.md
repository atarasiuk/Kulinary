# Фотографии

Фото готовых блюд. Папки повторяют структуру `recipes/`, имя файла = имя рецепта + дата приготовления:

```
images/dinners/fish/dorada-v-duhovke-2026-11-15.jpg
```

Фото вставляется в раздел «Мои результаты» рецепта:

```markdown
![Дорада, 15.11.2026](../../../images/dinners/fish/dorada-v-duhovke-2026-11-15.jpg)
```

Размер — до 1–2 МБ, лучше JPG шириной 1200 px.
