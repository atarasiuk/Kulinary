# Меню на неделю

Один файл на неделю: `meal-plans/ГГГГ/ГГГГ-Wнн.md` (номер недели по ISO), например `2026/2026-W46.md`.
Шаблон — [`templates/meal-plan-week.md`](../templates/meal-plan-week.md).

Правила подбора меню — в [`preferences.md`](../preferences.md): рыба по воскресеньям, в будни без рыбы, суточные дежурства обычно во вторник и четверг (нужна ссобойка).
