# Рецепты

Каждый рецепт — один файл `.md` в папке своей категории. Имя файла — транслит латиницей через дефис: `dorada-v-duhovke.md`.
Новый рецепт начинается с копии [`templates/recipe.md`](../templates/recipe.md).

| Папка | Что внутри |
|---|---|
| [`dinners/`](dinners/) | Основные горячие блюда, разложены по продукту |
| [`sides/`](sides/) | Гарниры, прежде всего картофель |
| [`soups/`](soups/) | Супы |
| [`breakfasts/`](breakfasts/) | Завтраки |
| [`salads/`](salads/) | Салаты и закуски |
| [`sauces/`](sauces/) | Соусы, маринады, заправки |
| [`baking/`](baking/) | Выпечка: хлеб, пироги, десерты |
| [`ssoboyka/`](ssoboyka/) | Еда с собой на суточное дежурство |

Одно блюдо лежит только в одной папке. Дополнительные признаки (воскресенье, ссобойка, аэрогриль, безлактозное) указываются тегами в метаданных `tags`, а не копией файла.
